# 1c-exchange-pipeline-demo

Демонстрационная конфигурация для
[1c-exchange-pipeline](https://github.com/i-simonov/1c-exchange-pipeline).

## Обновление ядра

Ядро переносится в демо-конфигурацию явным копированием из локального
репозитория:

```bash
git -C ../1c-exchange-pipeline pull --ff-only
./scripts/sync-core.sh
```

По умолчанию ожидается, что репозитории находятся рядом. Другой путь можно
передать аргументом:

```bash
./scripts/sync-core.sh /path/to/1c-exchange-pipeline
```

Скрипт копирует только объекты из своего белого списка и точечно переносит их
`configVersion` в `ConfigDumpInfo.xml`. Общие модули с суффиксом
`Переопределяемый`, `Configuration.xml`, подсистема и объекты демо-конфигурации
не синхронизируются. Коммит ядра, из которого выполнено копирование, записывается
в `CORE_VERSION`.

Репозиторий ядра должен быть без незакоммиченных изменений. После выполнения
скрипта изменения в демо-репозитории нужно проверить и закоммитить обычным
способом.
