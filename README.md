# 1c-exchange-pipeline-demo

Демонстрационная конфигурация для
[1c-exchange-pipeline](https://github.com/i-simonov/1c-exchange-pipeline).

## Обновление ядра

История репозитория связана с ядром через merge-base. Для первоначальной
настройки зависимости выполните:

```bash
./scripts/configure-core-dependency.sh
```

Последующие изменения ядра переносятся командой:

```bash
./scripts/update-core.sh
```

Общие модули с суффиксом `Переопределяемый` принадлежат демо-конфигурации и
автоматически сохраняются при слиянии. Конфликты в `Configuration.xml`,
`ConfigDumpInfo.xml` и подсистеме разрешаются вручную: демо-объекты и версии
переопределяемых модулей сохраняются, а изменения общих объектов принимаются
из ядра.
